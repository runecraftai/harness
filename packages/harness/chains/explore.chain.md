## scout

Recon de codebase read-only. CWD: repo do usuário.

PASSO 1 — Leia o contexto (context.md/prompt de origem) para delimitar o alvo do recon.

PASSO 2 — Mapeie o código relevante: módulos/fronteiras, arquivos-chave, fluxos — via read/grep/find/ls (zero edições, zero escrita).

PASSO 3 — Produza o relatório de recon COMPRIMIDO: o que existe onde (paths), como os fluxos se conectam, e pontos de entrada para a próxima fase.

Reportar: caminho do relatório (context.md) + mapa resumido.
